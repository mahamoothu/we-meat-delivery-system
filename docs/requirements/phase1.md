# Phase 1 Requirements & Boundaries

## In-Scope (Phase 1 Target Scope)

1. **Customer Mobile App (React Native / Expo)**:
   - Browse catalog, configure cuts/weight, cart management, checkout, order tracking.
2. **Shop Owner Mobile App (React Native / Expo)**:
   - Order management (Accept, Prepare, Dispatch, Complete), inventory availability toggle.
3. **Backend API (Node.js / Express / PostgreSQL / Prisma)**:
   - Product catalog, Order lifecycle, User authentication, Webhook ingestion.

## Explicitly Out-of-Scope for Phase 1

- No Delivery Partner App (Shop handles delivery assignment or customer pickup).
- No Multi-Shop Marketplace (Single shop setup for Phase 1).
- No Live GPS Driver Tracking.
- No Subscriptions, AI features, Wallets, or Loyalty engines.
